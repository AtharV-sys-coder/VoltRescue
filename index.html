VoltRescue

This file is only a signpost. The application is served by the API host, not from disk.

  1. Run start.ps1 (right-click, Run with PowerShell).
  2. The console prints the address. Open it.

Default address: http://127.0.0.1:8815/

The port is set by APP_PORT in .env. If Windows still holds a prefix after a hard kill, change APP_PORT and restart — that is the only place the port needs to change.
